# PROJECT RESUME: SECURE DATA WIPING - ENTERPRISE SANITIZATION
# Date: March 22, 2026

## 1. PROJECT OVERVIEW
Secure Data Wiping is a professional-grade forensic tool designed for irrecoverable data destruction. It utilizes context-aware algorithms to target files, folders, and entire drives while ensuring maximum security, zero trace on host machines, and legal-quality certification.

## 2. FINAL CORE ARCHITECTURE
- **Backend (core.py):** Context-aware engine with robust cross-platform storage detection (lsblk/PowerShell). Features low-level binary mutations and anti-forensic metadata erasure. Includes mandatory Administrative/Root privilege verification.
- **Frontend (app.py):** High-Performance Enterprise dashboard. Features dynamic grid scaling, system-native fonts (Segoe UI/Helvetica), and CTkTextbox-based protocol handling. Replaces standard popups with immersive custom overlays.
- **Certification (cert_generator.py):** Legal-grade document generation with institutional branding support, procedural security seals, and SHA-256 cryptographic signatures. Optimized for cross-platform image handling.
- **Launchers (run.sh / run.bat):** Automated cross-platform wrappers with isolated virtual environments and dependency synchronization.

## 3. COMPLETED "KICKASS" FEATURES
- **Aegis System Lock:** Hardcoded protection against accidental erasure of core OS files and User Profiles (Windows SystemRoot / Linux Root directories).
- **Smart Triage Engine:** Automatically assigns protocols: NIST SP 800-88 3-Pass (HDDs), AES-256 Crypto-Shredding (SSDs/Flash), and Header Corruption (Media).
- **Precision Desktop Detection:** Utilizes Windows Shell API (SHGetFolderPathW) and Linux xdg-user-dir to ensure certificates are always saved to the user's actual Desktop, regardless of localization or OneDrive redirection.
- **Enhanced Visual Feedback:** 
    - Brighter, high-contrast "Alive" UI theme.
    - High-impact "Obliterate Data" action button with glowing danger-state styling.
    - Real-time Stage Tracker integrated with high-visibility progress bar (22px).
- **Windows Optimization:** Comprehensive font standardization (Segoe UI), defined border scaling, and reliable physical drive access logic.
