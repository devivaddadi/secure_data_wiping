# Security Policy

## Supported Versions

Only the latest release version on the `main` branch of SDW is actively supported with security updates.

| Version | Supported |
| ------- | --------- |
| Latest  | ✅ Yes     |
| < 1.0   | ❌ No      |

## Reporting a Vulnerability

Because SDW handles irreversible destruction of data and system probes (with admin/root privileges), we take security seriously.

**Do not report security vulnerabilities via public GitHub issues.**

If you discover a security vulnerability (such as a privilege escalation bug, access bypass, or potential data leak), please report it responsibly by contacting the developer directly at the email listed on the GitHub profile or through GitHub's Private Vulnerability Reporting feature.

### What to Include in a Report:
*   A detailed description of the vulnerability.
*   Steps to reproduce the vulnerability, including code snippets or sample target types.
*   The potential impact of the vulnerability.

We will review the report and aim to provide a response and resolution plan within 48 to 72 hours.
